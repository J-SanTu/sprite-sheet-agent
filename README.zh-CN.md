## 从结构到交付

<p align="center"><img src="assets/readme/workflow.svg" width="100%" alt="设计动作结构 → 人工审核独立帧 → 导出 PNG 图集与 JSON"></p>

1. **设计结构** — 确认角色、动作和道具；按方向设计姿势、支撑、遮挡与接触，再审核模块边界和色板。
2. **逐帧审核** — 结构确认后，先生成关键姿势，再生成独立过渡帧。对照原参考、RAW、候选和相邻帧，记录修改意见。
3. **导出资产** — 人物组获得当前版本的人工批准后，打包图集与帧坐标、原点、时长等元数据。引擎接入单独安排。

### 哪些事情由工具负责

| 能力 | 实际行为 |
| --- | --- |
| 有效版本 | 审核页只展示 manifest 指定的组；文件哈希变化需更新映射，旧审核快照会失效。 |
| 同屏审核 | 结构、AI RAW、候选三栏；支持相邻帧、统一显示高度、多背景和逐帧播放。 |
| 程序保护 | C 合成回填同坐标静止区域，输出差异图、对照图与像素报告。 |
| 有界任务 | 离线请求包记录参考、预算和回执；在途任务恢复时查询原任务，阻止重复领取。 |
| 无损图集 | 对已获批准的当前人物组导出 PNG + JSON，检查裁切可逐像素还原。 |

**AI 宿主负责动作设计、视觉分析与实际生图；用户负责确认。** 本包不内置图像服务、自动美术验收或游戏引擎插件。

## 快速开始

先运行无需 API 的匿名演示。要求 **Python 3.10+、Pillow、macOS 或 Linux**；当前任务锁使用 `fcntl`，Windows 原生运行尚不支持。

在本包根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install Pillow
python3 scripts/build_demo.py ../sprite-agent-demo
```

在浏览器中打开 `../sprite-agent-demo/review/index.html`。你会得到结构、测试色块、逐帧播放器和意见导出控件。色块只是审核界面测试素材，不是生成的人物。

输出目录必须为空；再次运行请换新目录。演示中的图片、GIF 和 manifest 都由本地脚本生成，不会调用生图 API。

## 交给 AI 助手使用

将**整个文件夹**安装为 `sprite-sheet-agent`，保持 `SKILL.md` 位于顶层。素材和运行结果放在另外的工作目录。

| 宿主 | 入口 |
| --- | --- |
| Codex | 放入宿主配置的技能目录，例如 `~/.codex/skills/sprite-sheet-agent/`，重新加载后调用 `$sprite-sheet-agent`。 |
| Claude Code | 放入 `~/.claude/skills/sprite-sheet-agent/` 或项目技能目录，重新加载后调用 `/sprite-sheet-agent`。 |
| 其他助手 | 提供整个包，让助手读取 [AGENT.md](AGENT.md)、[SKILL.md](SKILL.md) 和[生产规则](references/production-method.md)。 |

这些宿主安装入口尚未完成真实会话验证；以上是配置说明，不是兼容性认证。只上传 README 不会加载完整规则。助手需要文件读写和视觉能力；生图由你选择的内置工具或 API 提供。

准备获认可的正面、侧面、背面设定、目标尺寸和动作列表。不对称角色补充另一侧；道具提供独立基准。可以这样开始：

> 使用 sprite-sheet-agent，工作目录为我指定的角色目录。检查我的三视图，规划四方向行走、坐下与起身。先提交动作清单、道具基准和彩色结构；我确认后再制作独立人物帧。每组更新固定审核页，保留原图、RAW 和失败版本。

## A / B / C 怎么选

| 方法 | 模型阶段 | 输出处理 |
| --- | --- | --- |
| **A** | 原图 + 编辑蒙版 + 短任务词 | 保留模型返回，人工检查。 |
| **B** | A 的输入 + 当前任务 JSON | 保留模型返回，人工检查。 |
| **C** | 与 B 相同 | 按独立保护蒙版回填原像素，再检查接缝与动作。 |

模型不支持蒙版时，必须记录降级。JSON 是约束，不保证模型逐字段遵守。C 只适合已经确认不移动、同尺寸同坐标的区域；坐下、转向和跑步不能机械锁定旧头部位置。

同一源图和模型返回最多尝试 **两版 C 合成**，第二版必须改变有效 alpha 边界。它们不等于两次额外生图。模型调用次数与费用另外确认：每帧三次总生成只是默认建议，既有任务上限优先。没有合格候选就记录待修。

## 当前边界

离线演示与部分校验已有记录；真实宿主加载、外部生图质量、完整角色生产和引擎接入仍需验证。英文版覆盖 README 与操作指南；技能规则、模板提示和审核界面目前主要为中文。

颜色采样和视觉判定由宿主按确认的模块进行，本包没有自动颜色检测器。原图与 RAW 保留，技术检查、自审、用户确认和引擎验证分别记录。结构示意允许脚本绘制；最终人物动作不使用镜像、拼肢体或自动补帧伪造。
